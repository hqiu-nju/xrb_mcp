This directory is reserved for a manually verified, licensed reference corpus and
scientific retrieval benchmarks. No papers or astrophysical claims are seeded by
the framework. The PDFs generated by automated tests are explicitly synthetic.

Before declaring the scientific MVP complete, add 20–50 reviewed papers, expected
aliases, query-to-paper relevance labels, and page/section evidence checks. Measure
recall@k, precision@k, MRR and citation correctness; include upper-limit and
ambiguous-identity cases when structured observations are implemented.
